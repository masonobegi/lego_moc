**LDraw Parts Library**, licensed under the

Contributor Agreement.

> LDraw is an open standard for LEGO CAD programs that allow the user to create
> virtual LEGO models and scenes. The LDraw Parts Library is the work of many
> volunteer authors.

**Credit: LDraw.org and the individual part authors named in each part file.**

What this repository redistributes:

| Path | Contents |
| --- | --- |
| `public/ldraw/parts/`, `public/ldraw/p/` | A subset of the parts library: the transitive closure of the parts used by the built-in fixtures and the demo price table, about 370 files. Original headers, including `0 Author:` and `0 !LICENSE`, are preserved byte for byte. |
| `public/ldraw/LDConfig.ldr` | The official colour definitions. |
| `public/ldraw/CAreadme.txt`, `public/ldraw/CAlicense.txt` | The LDraw Parts Library Agreement and its legal code, unmodified. |
| `src/lib/ldraw/colors.generated.ts` | Generated from `LDConfig.ldr` by `npm run colors:build`. A derived work; the same attribution applies. |
| `public/ldraw/bundled-parts.json` | Manifest of what was copied and from where. |

The full library is not committed. `npm run parts:fetch` installs it from
<https://library.ldraw.org/> (falling back to a GitHub mirror), into
`public/ldraw-full/`, which is git-ignored.

Licence text: <http://creativecommons.org/licenses/by/2.0/> and
`public/ldraw/CAlicense.txt`.

## LDraw Official Model Repository

`data/catalog/bundled-catalog.json` is **derived aggregate data** generated by
`scripts/build-bundled-catalog.ts` from LDraw Official Model Repository files.
It records which `(part, colour)` combinations were observed in which official
LEGO sets, and nothing else - no geometry, no model structure, no model file.

OMR files are individually authored and licensed CC BY 2.0.
**Credit: LDraw.org and the individual model authors.**

No OMR model file is committed to this repository. `npm run parts:fetch --
--mirror --models` downloads them into `test-models/omr/`, which is git-ignored.

`data/catalog/mold-rules.json` is derived from the *descriptions* in official
LDraw part files, generated by `scripts/build-mold-rules.ts`.

## Rebrickable

`npm run catalog:import` downloads catalogue CSVs from
<https://rebrickable.com/downloads/>. Rebrickable permits use of that data for
any purpose including commercial, **provided Rebrickable is acknowledged as the
source of the data**, and permits automated download at most once per day. The
import script enforces the once-per-day rule and stamps the acknowledgement into
the file it writes.

No Rebrickable data is committed to this repository.

## BrickLink

BrickLink price data is only ever fetched at runtime through the official
BrickLink Store API, with credentials the user supplies, and is never
redistributed. This project does not scrape BrickLink.

The Wanted List XML format follows BrickLink's documented import format.

## Demo price data

The prices in `src/lib/pricing/demoData.ts` are **synthetic**. They are not real
marketplace prices, were not derived from any marketplace's data, and are
labelled `DEMO PRICE DATA` everywhere the application displays them.
